Project Title: (CropGuard) An IoT-Based Smart Agriculture Monitoring & Automation System

Description: An IoT-Based Smart Agriculture Monitoring & Automation System

Technologies Used: -
- Frontend Framework: Flutter (Cross-platform Web & Mobile deployment compatible)
- Programming Language: Dart
- Hardware Architecture (IoT): Arduino Uno Microcontroller, ESP8266 Wi-Fi Module
- Sensors: GUVA-S12SD/ML8511 UV Sensor Radiation Probe, DHT11 Temperature & Humidity Sensor

Features: List the features you plan to implement

- Live Microclimate Dashboard: Real-time displays for UV Radiation Intensity indices paired with corresponding ambient temperature and air humidity readings.
- Dynamic Graphical Tracking: Interactive historical curve monitors mapping daily UV accumulation doses alongside 24-hour/7-day progression lines.
- Remote Automation Controls: Over-the-air threshold configuration rules enabling remote adjustments to safety limits, push notifications toggle states, and physical buzzer commands.
- Historical Dispatch Records: Persistent warning logs noting precise times, severity levels, and specific telemetry markers measured during threshold breach events.
- Integrated IoT Hardware Simulator: Built-in modular control deck mimicking field telemetry changes directly on the application UI for system assessment.
